# Mengatur Pengiriman (Seller)

1. Di menu **Akun → Dashboard Penjual → Kelola Pesanan**.

   ![Kelola Pesanan](https://cdn2.pokepedia.id/tutorial/tutorial-5.1.webp)

2. Klik nomor pesanan yang mau diproses.

Pilih salah satu cara kirim:

## Opsi A — Pickup oleh Kurir (dijemput)

3. Klik **Pickup oleh kurir** → sistem otomatis membuat resi.

   ![Request Pickup](https://cdn2.pokepedia.id/tutorial/tutorial-5.2.webp)

4. Klik **Cetak Resi** → print label → tempel di paket.

   ![Cetak Resi](https://cdn2.pokepedia.id/tutorial/tutorial-5.3.webp)

5. Tunggu kurir datang ke alamatmu.

   ![Tunggu Pickup](https://cdn2.pokepedia.id/tutorial/tutorial-5.4.webp)

## Opsi B — Drop Sendiri ke Kurir

3. Antar paket sendiri ke counter kurir → bayar ongkir di awal.

   ![Drop ke Counter](https://cdn2.pokepedia.id/tutorial/tutorial-5.5.webp)

4. Input nomor resi secara manual di halaman pesanan.

5. Kamu akan mendapat penggantian ongkir dari pembeli.

> ⚠️ **Penting:** Tombol "Cetak Slip Alamat" hanya mencetak label berisi alamat — tanpa resi. Untuk mendapatkan resi, gunakan **Request Pickup** terlebih dahulu, kemudian klik **Cetak Resi**.

> ⚠️ **Penting:** Jika memilih "Pickup oleh kurir", paket tidak bisa diantar sendiri ke counter kurir. Tunggu kurir datang menjemput. Jika ingin drop off sendiri, gunakan opsi "Kirim sendiri".

## FAQ

### Kapan uang masuk ke saldo?

Setelah pembeli mengkonfirmasi paket diterima. Jika tidak ada konfirmasi, uang otomatis cair 2 hari setelah estimasi tiba.

### Pembeli tidak merespons, paket sudah dikirim — bagaimana?

Tidak perlu khawatir. Uang otomatis diteruskan ke saldo kamu 2 hari setelah status paket "diterima" menurut kurir.

### Bisa kirim ke luar kota?

Bisa, sesuai jangkauan kurir yang kamu pilih saat setup toko.
