# Menarik Penghasilan (Withdraw)

1. Klik **Dashboard Penjual** → di kanan atas, pilih **Saldo Dompet**.

   ![Saldo Dompet](https://cdn2.pokepedia.id/tutorial/tutorial-6.1.webp)

2. Tambahkan rekening bank tujuan → isi detail → simpan.

   ![Tambah Rekening](https://cdn2.pokepedia.id/tutorial/tutorial-6.2.webp)

3. Klik **Tarik Saldo** → konfirmasi.

   ![Tarik Saldo](https://cdn2.pokepedia.id/tutorial/tutorial-6.3.webp)

## FAQ

### Berapa minimum tarik saldo?

Rp10.000,00.

### Berapa lama proses pencairan?

Umumnya langsung cair selain tengah malam. Maksimal 1×24 jam.

### Di mana lihat riwayat transaksi penjualan?

**Akun → Dashboard Penjual → Pesanan.** Untuk pesan dari pembeli: Toko → chat tersedia di sana.
