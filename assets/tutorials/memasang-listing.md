# Memasang Ask (WTS) / Listing

> **Syarat sebelum mulai:** verifikasi nomor HP, pasang alamat, dan pilih minimal satu kurir. Ketiganya wajib ada — tanpa salah satu, tombol listing tidak akan aktif.

## Lengkapi profil toko dulu (sekali saja)

1. Klik **Dashboard Penjual** (di menu akun).

   ![Dashboard Penjual](https://cdn2.pokepedia.id/tutorial/tutorial-3.1.webp)

2. Dari beranda dashboard, klik **Toko**.

   ![Halaman Toko](https://cdn2.pokepedia.id/tutorial/tutorial-3.2.webp)

3. Gulir ke bawah → isi dan simpan **alamat pengiriman** (pinpoint akurat).

   ![Isi Alamat](https://cdn2.pokepedia.id/tutorial/tutorial-3.3.webp)

4. Pilih **kurir** yang tersedia di area kamu (bisa lebih dari satu).

   ![Pilih Kurir](https://cdn2.pokepedia.id/tutorial/tutorial-3.4.webp)

5. Opsional: tambah foto profil + banner toko.

   ![Foto Profil & Banner](https://cdn2.pokepedia.id/tutorial/tutorial-3.5.webp)

## Pasang listing

6. Di dashboard penjual → tab **Listing** → klik **Tambahkan Listing**.

   ![Tambahkan Listing](https://cdn2.pokepedia.id/tutorial/tutorial-3.6.webp)

7. Ketik nama kartu yang mau dijual di kolom pencarian.

   ![Cari Kartu](https://cdn2.pokepedia.id/tutorial/tutorial-3.7.webp)

8. Atur harga, kondisi, dan kuantitas → centang baris kartu di sebelah kiri → klik **Pasang Terpilih**.

   ![Pasang Terpilih](https://cdn2.pokepedia.id/tutorial/tutorial-3.8.webp)

9. *Cara alternatif:* buka halaman detail kartu → di bagian Order Book → klik **Pasang Ask**.

   ![Pasang Ask dari Detail Kartu](https://cdn2.pokepedia.id/tutorial/tutorial-3.9.webp)

10. Cek listingmu di `pokepedia.id/market/[username]`.

    ![Cek Listing](https://cdn2.pokepedia.id/tutorial/tutorial-3.10.webp)

## FAQ

### "Profil toko belum lengkap" padahal sudah isi alamat?

Kurir belum dipilih. Kembali ke halaman **Toko → scroll ke bawah → centang kurir** yang tersedia di daerahmu.

### Bisa jual kartu slab / graded?

Bisa. Saat mengisi listing, pilih kondisi sesuai gradenya. Data harga pun otomatis dipisah per kondisi.

### Bisa jual per set / deck / lot?

Belum tersedia. Saat ini listing hanya per kartu (single).

### Berapa lama listing aktif?

30 hari. Aktifkan toggle **Perbarui Otomatis** agar listing diperpanjang sendiri setelah 30 hari.

### Apa itu toggle "Penawaran"?

Jika diaktifkan, pembeli bisa mengajukan harga tawar sebelum checkout.

### Di mana lihat semua listingku?

**Dashboard Penjual → Listing Aktif.** Atau: Akun → Lihat Profil → Lihat Toko.
