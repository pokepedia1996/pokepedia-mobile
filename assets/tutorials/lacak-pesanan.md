# Lacak Pesanan & Konfirmasi Terima

## Sebagai Pembeli

1. Klik **Akun → Pesanan** untuk lihat semua pesanan aktif.

   ![Daftar Pesanan](https://cdn2.pokepedia.id/tutorial/tutorial-9.1.webp)

2. Klik nomor pesanan untuk lihat detail dan nomor resi.

   ![Detail Pesanan](https://cdn2.pokepedia.id/tutorial/tutorial-9.2.webp)

3. Lacak paket lewat nomor resi di situs kurir.

   ![Lacak Resi](https://cdn2.pokepedia.id/tutorial/tutorial-9.3.webp)

4. Setelah paket diterima → klik **Konfirmasi Penerimaan** → dana diteruskan ke seller.

   ![Konfirmasi Penerimaan](https://cdn2.pokepedia.id/tutorial/tutorial-9.4.webp)

> Jika tidak dikonfirmasi dalam 2×24 jam setelah status "terkirim", sistem otomatis konfirmasi dan dana cair ke seller.

## FAQ

### Tombol "Konfirmasi Penerimaan" tidak muncul?

Muncul hanya setelah seller input resi dan status pengiriman terupdate. Tunggu beberapa saat setelah paket dikirim.

### Sudah konfirmasi tapi barang bermasalah — bisa komplain?

Bisa, selama masih dalam batas waktu 2×24 jam setelah konfirmasi. Gunakan **Pusat Resolusi**.
